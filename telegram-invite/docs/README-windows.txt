ЧЕРНОВИКИ ПРИГЛАШЕНИЙ В TELEGRAM — Windows
==========================================

Python и что-либо ещё устанавливать не нужно.


КАК ЗАПУСТИТЬ
-------------

1. Распакуйте архив (правый клик -> «Извлечь все») и положите папку,
   например, в «Документы». Не запускайте прямо из архива — программе
   нужно сохранять файлы рядом с собой.

2. Двойной клик по telegram-invite.exe.

3. Если появится синее окно «Система Windows защитила ваш компьютер»:
      «Подробнее» -> «Выполнить в любом случае».
   Так Windows реагирует на любую программу без платной подписи.

4. Если антивирус ругается — это ложное срабатывание, типичное для
   программ, собранных таким способом. Добавьте файл в исключения.


ЧТО СПРОСИТ ПРИ ПЕРВОМ ЗАПУСКЕ
------------------------------

api_id и api_hash — их надо получить один раз на https://my.telegram.org
(войти по своему номеру -> API development tools -> создать приложение).

Потом номер телефона и код подтверждения. Код придёт в само приложение
Telegram, в чат «Telegram». Дальше программа помнит вход.


ЧТО ПОЯВИТСЯ РЯДОМ С ПРОГРАММОЙ
-------------------------------

credentials.json  — ваши ключи и настройки. Никому не показывайте.
template.txt      — текст приглашения. Правится «Блокнотом».
contacts\         — списки контактов, выгруженные из Google-таблицы.
state\            — файл входа и отметки о том, кто уже обработан.

Папку state\ не удаляйте: без неё придётся логиниться заново, а программа
забудет, кому черновики уже сделаны.


ВАЖНО
-----

Программа НИЧЕГО НЕ ОТПРАВЛЯЕТ. Она только кладёт готовый текст в поле
ввода нужного диалога. Отправляете вы сами, руками, прочитав текст.
