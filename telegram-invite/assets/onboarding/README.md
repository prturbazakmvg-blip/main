# Скриншоты для мастера первого запуска

Мастер (`app/onboarding.py`) на каждом шаге сначала ищет здесь настоящий
скриншот. Файла нет — рисуется схема, поэтому класть их можно по одному.

| Файл | Что на нём | Откуда |
|---|---|---|
| `step1-phone.png` | форма ввода номера на my.telegram.org | есть, снят автоматически |
| `step2-code.png` | страница ввода кода подтверждения | нужен вход в аккаунт |
| `step3-tools.png` | список разделов со ссылкой «API development tools» | нужен вход |
| `step4-create.png` | форма «Create new application» | нужен вход |
| `step5-keys.png` | страница с api_id и api_hash | **не добавлять** |

`step1-phone.png` снят так:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless \
  --disable-gpu --hide-scrollbars --window-size=660,600 --virtual-time-budget=4000 \
  --screenshot=assets/onboarding/step1-phone.png https://my.telegram.org
```

Остальные страницы доступны только после входа в аккаунт, поэтому снимаются
руками: Cmd+Shift+4, выделить область страницы, файл переименовать по таблице
и положить сюда. Размер любой — картинка ужимается сама (retina 2x тоже).

## Про шаг 5

Страницу с ключами скриншотить не надо. Она попадёт в приложение, которое
раздаётся другим людям, а api_hash — это доступ к вашему аккаунту от имени
приложения. На этом шаге специально нарисована схема с выдуманными
значениями.

## Подсветка

Рамки и стрелки поверх скриншота задаются функциями `marks_*` в
`app/onboarding.py` — координаты считаются от левого верхнего угла картинки.
После замены файла их надо подогнать.
