# Черновики приглашений в Telegram

Раскладывает персональные приглашения черновиками по личным диалогам в Telegram.
**Ничего не отправляет** — текст просто оказывается в поле ввода нужного чата,
отправляет человек руками.

Контакты берутся из Google-таблицы, текст — из шаблона, имя подставляется.

## Для тех, кто просто пользуется

Скачайте архив со страницы [Releases](https://github.com/prturbazakmvg-blip/main/releases) под свою систему,
распакуйте и запустите. Python устанавливать не нужно.

| Система | Файл | Как запустить |
|---|---|---|
| Mac с Apple Silicon (M1–M4) | `telegram-invite-macos-arm64.zip` | двойной клик по «Черновики приглашений» |
| Mac на Intel | `telegram-invite-macos-intel.zip` | двойной клик по «Черновики приглашений» |
| Windows | `telegram-invite-windows.zip` | двойной клик по `telegram-invite.exe` |

На macOS это обычное приложение с окном. На Windows пока только консольный
мастер — оконная версия под неё не собиралась.

Подробные инструкции, включая обход предупреждений Windows SmartScreen и
macOS Gatekeeper, лежат внутри архива в файле «Прочитай меня.txt»
(исходники — [docs/](docs/)).

При первом запуске откроется мастер из пяти шагов: он по скриншотам показывает,
где на my.telegram.org взять `api_id` и `api_hash`. Вызвать его потом заново —
«Настройки» → «Показать инструкцию».

## Где хранятся данные

`~/Library/Application Support/TelegramInvite/` (на Windows — `%APPDATA%\TelegramInvite`):

```
credentials.json   ключи, настройки и текст приглашения  ← не показывать никому
state/             вход в Telegram и отметки «кому уже сделан черновик»
```

Отдельно от приложения — намеренно. Раньше всё лежало рядом с `.app`, и это
ломалось: копий приложения на диске оказывается несколько (рабочая, `dist`,
`release`), у каждой своё состояние, а Finder запускает ту, на которую нажали;
плюс папку рядом сносила пересборка. Теперь место одно. При первом запуске
новой версии данные из старой папки переносятся автоматически.

Вход восстанавливается при запуске сам — код из Telegram спрашивается только
один раз.

## Окно

Один экран, четыре шага сверху вниз. Пройденный шаг помечается галочкой,
в заголовке видно выбранное; шаг 4 недоступен, пока не готовы предыдущие.

1. **Вход в Telegram** — номер, код, при необходимости облачный пароль.
2. **Кому пишем** — либо Google-таблица (читается живьём при каждом нажатии,
   ничего не сохраняется на диск, поэтому правки подхватываются сразу; дальше
   выбор группы по колонке «кто напишет»), либо папка чатов в Telegram. Во
   втором случае `ResolveUsername` не вызывается вообще: люди уже в диалогах.
   Список папок берётся одним `messages.GetDialogFilters`, участники
   дочитываются только для выбранной папки.
3. **Что пишем** — редактор прямо в окне (самое большое поле на экране,
   текст сохраняется сам), либо персональный текст из колонки таблицы
   (колонка находится по заголовку «Сообщение» / «Текст»).
4. **Проверить и разослать** — пробный прогон (тексты на экран, Telegram не
   трогается, никто не помечается), затем рассылка партиями с кнопкой «Стоп».

Обработанные запоминаются, поэтому следующая партия берёт только оставшихся —
дублей не бывает. Ключи, паузы и лимит спрятаны в отдельное окно «Настройки».

## Шаблон

Поддерживаются `{NAME}` и `{USERNAME}`, а также голые `NAME` / `USERNAME`.

Правится на шаге 3 прямо в окне и хранится вместе с настройками —
отдельный файл выбирать не нужно. Несколько вариантов текста
разделяются строкой из трёх дефисов — для каждого контакта вариант выбирается
случайно:

```
Привет, {NAME}! Мы проводим AI Growth Day 28 августа...
---
{NAME}, привет. 28 августа в Екатеринбурге AI Growth Day...
```

Это не косметика: сотня абсолютно одинаковых сообщений — самый заметный
признак рассылки.

## Что сделано против ограничений Telegram

Рискованная часть работы — не запись черновика, а `contacts.ResolveUsername`:
обращение к Telegram за незнакомым username. Именно оно лимитируется.

- случайная пауза 20–45 с между контактами (настраивается);
- мягкий дневной потолок 30 черновиков с предупреждением при превышении;
- `FLOOD_WAIT` до 5 минут пережидается и работа продолжается, больше — прогон
  останавливается;
- `PEER_FLOOD` (аккаунт уже придержали) — немедленная остановка с объяснением;
- отметки об обработанных контактах: повторный запуск не резолвит те же
  username заново;
- файл сессии не удаляется никогда, кроме явного «Выйти из аккаунта» в меню;
- постоянные `device_model` / `app_version`, чтобы сессия не выглядела скачущей.

Чего программа сделать не может: если после раскладки черновиков отправить
сотню почти одинаковых сообщений людям, которых нет у вас в контактах, часть
получателей нажмёт «Пожаловаться» — и аккаунт получит спам-блок. Пишите с
живого прогретого аккаунта, не со свежей SIM, и не гоните объём.

Если ограничение всё же прилетело — напишите в @SpamBot.

## Для разработчика

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

Неинтерактивный режим:

```bash
python run.py --download                                  # обновить списки из таблицы
python run.py --csv contacts/иван.csv --dry-run --count 5  # показать тексты, без Telegram
python run.py --csv contacts/иван.csv --count 20           # создать 20 черновиков
```

`create_messages.py` оставлен как заглушка совместимости со старым запуском.

### Сборка

Кросс-компиляции нет: `.exe` собирается только на Windows, бинарник для
macOS — только на macOS.

Через GitHub Actions (`.github/workflows/build.yml`) — пуш тега соберёт
все три варианта и приложит их к релизу:

```bash
git tag v2.0.0 && git push origin v2.0.0
```

Локально:

```bash
bash packaging/build-gui.sh                                          # macOS, окно
bash packaging/build-local.sh                                        # macOS, консоль
powershell -ExecutionPolicy Bypass -File packaging\build-local.ps1   # Windows
```

Оконной сборке нужен tkinter. В Homebrew-питоне его нет, ставится один раз:

```bash
brew install python-tk@3.13
```

Важно, чтобы это был Tcl/Tk 9: версия 8.6 не умеет символы вне BMP и ломает
эмодзи в шаблоне. Приложение проверяет это само и пишет предупреждение в лог.

Сборки не подписаны. Windows покажет SmartScreen, macOS — Gatekeeper.
Чтобы это убрать, нужны сертификат Microsoft Authenticode и Apple Developer ID
с нотаризацией; тогда в workflow добавляются шаги `signtool` и
`codesign --options runtime` + `notarytool`.

### Структура

```
app/paths.py      пути (Application Support) и перенос из старой папки
app/config.py     credentials.json, значения по умолчанию
app/sheets.py     выгрузка и разбор Google-таблицы
app/contacts.py   контакты: живое чтение таблицы и старые csv
app/templates.py  шаблоны и подстановка
app/progress.py   отметки «обработано» и дневной счётчик
app/session.py    подключение и вход в Telegram
app/drafts.py     создание черновиков, паузы, обработка FLOOD_WAIT
app/main.py       консольный мастер
app/gui.py        окно (tkinter): tk в главном потоке, asyncio в фоновом
app/onboarding.py мастер первого запуска со скриншотами
app/tgfolders.py  папки чатов Telegram (messages.GetDialogFilters)
app/ui.py         ввод-вывод консоли
```

Скриншоты для мастера и как их доснять — [assets/onboarding/README.md](assets/onboarding/README.md).
