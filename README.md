# Address Distance Calculator

Сервис принимает таблицу (.xlsx/.csv) с адресами, считает расстояние по дороге
(автомобильный маршрут, Яндекс Router API) между парой столбцов «откуда»/«куда»
в каждой строке, округляет вверх до целых километров и возвращает таблицу с
добавленным столбцом результата.

## Запуск

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Открыть http://localhost:8000

## Использование

1. Загрузить файл .xlsx или .csv.
2. Выбрать столбец «откуда» и столбец «куда».
3. Ввести API-ключ Яндекс (нужны права на Geocoder API и Router API,
   https://developer.tech.yandex.ru/).
4. Нажать «Рассчитать и скачать» — браузер скачает обработанный файл с новым
   столбцом «Расстояние, км».

Ключ API не сохраняется на сервере — передаётся только в рамках запроса на
обработку.
