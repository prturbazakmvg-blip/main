# Address Distance Calculator

Сервис принимает таблицу (.xlsx/.csv) с адресами, считает расстояние по дороге
(автомобильный маршрут на машине, через OSRM) между парой столбцов
«откуда»/«куда» в каждой строке, округляет вверх до целых километров и
возвращает таблицу с добавленным столбцом результата. Геокодирование адресов
выполняется через OSM Nominatim. Оба сервиса бесплатные и не требуют ключей.

## Запуск

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Открыть http://localhost:8000

## Использование

1. Загрузить файл .xlsx или .csv.
2. Выбрать столбец «откуда» и столбец «куда».
3. По желанию указать город — он будет добавлен перед каждым адресом при
   поиске, чтобы избежать неоднозначности коротких адресов вида «Ленина 1».
4. Нажать «Рассчитать и скачать» — браузер скачает обработанный файл с новым
   столбцом «Расстояние, км».

## Ограничения бесплатных сервисов

- Nominatim ограничивает геокодирование 1 запросом в секунду — большие
  таблицы обрабатываются дольше.
- Оба сервиса (Nominatim, OSRM) — публичные демо-инстансы с разумными
  лимитами на объём; для промышленной нагрузки стоит поднять собственные
  инстансы или перейти на платные тарифы.
